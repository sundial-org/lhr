# Design explorations

Eleven standalone landing-page directions for longhorizonresearch.com. Each folder is a self-contained `index.html` (open directly in a browser, or serve the repo root) with a `preview.png`.

## Adaptations — a reference site's design language, rebuilt with LHR content

| Folder | Source language | Note |
| --- | --- | --- |
| `adapt-trainloop` | trainloop.ai | Painterly skies, serif display, procedural paintings |
| `adapt-hermes` | hermes-agent.nousresearch.com | Electric blue, didone caps, generated engravings |
| `adapt-terraform` | terraformindustries.com | Bare HTML, monospace, ASCII art, zero JS |
| `adapt-inheritance` | inheritance.ai | Cream paper, script wordmark, dotted-leader index |
| `adapt-elizaos` | elizaos.ai | Color-block sections, giant grotesque type |
| `adapt-refresh` | refresh.dev | Product-site polish; candidate for sundial.md rather than the lab |
| `adapt-recurrent` | recurrent.org | Single-screen kinetic art object, live canvas |

## Variants and originals

| Folder | Concept |
| --- | --- |
| `induction-variant` | inductionlabs.com system (paper, column grid, pill nav) with an hour-line fan mark |
| `round2-review` | Broadsheet front page crossed with a museum catalogue |
| `round2-atelier` | Engraver's atelier; human and mechanical hand writing one line |
| `round2-horizon` | One painted dawn the page lives inside |

No text, images, logos, or code were copied from the reference sites; each adaptation recreates the design system with original copy and newly generated or hand-drawn artwork.
